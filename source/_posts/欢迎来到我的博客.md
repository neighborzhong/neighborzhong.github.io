你好！欢迎来到我的博客 👋

这是我的第一篇博客文章。这个博客使用 **Hexo** 框架和 **NexT** 主题搭建，部署后会免费托管在 GitHub Pages 上。

## 我能在这个博客上做什么

- ✍️ 用 Markdown 写文章，记录学习笔记和生活点滴
- 🚀 一条命令发布更新
- 🎨 切换主题风格、自定义页面

## 接下来可以做什么

1. 在 `_config.yml` 里修改博客标题和作者名（现在还是占位符）
2. 创建标签页和分类页
3. 把博客部署到 GitHub Pages，获得一个免费的网址

祝写作愉快！
